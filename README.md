# CreditBridge

A web application designed to help community college students find the best transfer paths to complete their bachelor's degree without wasting credits or time.

## Features

- AI powered chatbot advisor
- Personalized degree transfer plans
- University program search and comparison
- Downloadable PDF degree plan
- Save and revisit past plans

## Tech Stack

**Frontend:** React, Vite
**Backend:** Flask, Python
**Database:** MongoDB Atlas
**AI:** Claude API
**PDF Generation:** ReportLab
**Web Scraping:** BeautifulSoup

## Getting Started

### Prerequisites
- Python 3.x
- Node.js v18+
- MongoDB Atlas account

### Installation

**Backend**
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```
